# Gatherly — Smart Celebration & Event Planner

**Plan celebrations beautifully. Manage every detail effortlessly.**

Gatherly is a modern event-planning web application designed to simplify the process of organizing celebrations. From weddings and birthdays to anniversaries and college events, Gatherly brings event details, guest lists, budgets, schedules, and tasks together in one centralized dashboard.

Built with an emphasis on usability, responsive design, and practical functionality, Gatherly aims to make event planning more organized and efficient.

## Key Features

### Interactive Dashboard
- View upcoming celebrations and event progress.
- Track today's tasks and upcoming deadlines.
- Review reminders, alerts, and important updates.
- Visualize event or task completion through charts.
- Access essential planning information from one dashboard.

### Event Management
- Create, edit, duplicate, and delete events.
- Organize weddings, birthdays, anniversaries, and other celebrations.
- Track event dates, details, and planning progress.
- View and manage upcoming events.

### Guest and RSVP Management
- Maintain guest lists for individual events.
- Track RSVP statuses: Invited, Attending, Maybe, and Declined.
- Monitor RSVP summaries and attendee counts.
- Search and filter guest records.

### Budget and Expense Tracking
- Set budgets for individual celebrations.
- Record estimated and actual expenses.
- Categorize expenses such as venue, catering, decoration, and photography.
- Calculate spending totals and remaining budgets.
- Identify overspending through budget indicators.

### Task and Checklist Management
- Create and organize event-related tasks.
- Set priorities and due dates.
- Track pending, completed, and overdue tasks.
- Monitor progress using interactive checklists.
- Use event-specific checklist templates where implemented.

### Calendar and Scheduling
- Navigate event dates and schedules.
- Organize upcoming celebrations and deadlines.
- Keep important dates accessible in one place.

## Design and User Experience

Gatherly uses a clean dashboard inspired by modern event-management interfaces.

- Warm ivory and cream backgrounds.
- Pastel lavender, peach, and powder-blue accents.
- Rounded panels and compact event cards.
- Sidebar navigation and clear active states.
- Charts and progress indicators.
- Responsive layouts for desktop, tablet, and mobile.
- Readable typography and clear visual hierarchy.

## Testing and Quality Assurance

Evaluate the application across the following areas:

- **Functionality:** Verify event, guest, task, and expense operations.
- **Data consistency:** Check dashboard totals, RSVP counts, and event progress.
- **Persistence:** Confirm saved data remains available after refreshing the page.
- **Validation:** Test invalid inputs, empty fields, dates, and monetary values.
- **Edge cases:** Check zero budgets, overspending, empty lists, and deleting events with related records.
- **Responsiveness:** Test mobile, tablet, and desktop layouts.
- **Accessibility:** Verify keyboard navigation, visible focus states, form labels, and readable contrast.
- **Performance:** Check for unnecessary delays, layout shifts, and console errors.
- **Security:** Validate user input and handle stored data safely.

## Data and Privacy

If the application uses browser LocalStorage, data is stored locally in the user's browser. This does not provide automatic cloud synchronization or secure multi-user storage. Clearing browser data may remove saved records.
